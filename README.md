## Русский

### Кварто-квинтовый круг

Приложение для заучивания и проверки выученного кварто-квинтового круга, аккордов на нем и тональностей, а затем проверка ваших знаний

#### 1. Какие есть функции у приложения

Приложение состоит из **трёх вкладок** вверху экрана:

**Вкладка «Обучение»**
Режим для изучения. Нажимаете на любую ноту на круге — приложение показывает:
- обычные аккорды (мажор/минор), а также Sus2, Sus4 и расширенные аккорды (7, maj7, m7, 9, 11, 13 и их варианты) — всего 20 типов аккордов;
- лады (мажор, минор, дорийский, фригийский, лидийский, миксолидийский, локрийский), а также отдельно гармонический и мелодический минор (у них есть свои условия — написаны в подсказке, сделаны для простоты запоминания).

Ноты аккорда/лада можно показывать двумя способами:
- **Стрелками** — прямо на круге рисуются стрелки от тоники к остальным нотам аккорда/лада;
- **Цветом** — нужные ноты просто подсвечиваются цветом.

Рядом с кругом можно включить мини-клавиатуру пианино (в настройках галочка), которая дублирует те же ноты на клавишных.

**Вкладка «Ноты»**
Режим для проверки выученного
- Клик мыши — в центре отображается нота, надо нажать на неё на круге мышью (для миди пк/миди клавиатуры следующий пункт).
- На пк/миди клавиатуре — нота выделена цветом, надо нажать на клаве пк/миди клавиатуре.
- Кнопки мажор и минор просто выбирают все ноты на мажорном и на минорном кольце.
- Скрыть ячейки круга — отвечать нужно на клавиатуре справа, вспоминая именно ноты, а не шаблон.
- Кнопка убрать все — оставляет выбранной только ноту C.

**Вкладка «Аккорды/Лады»**
То же самое, что «Ноты», но проверяется знание аккордов и ладов: приложение загадывает аккорд или лад, нужно правильно указать все его ноты на круге.

**Общие для всех вкладок функции**
- Подключение MIDI-клавиатуры — можно подключить MIDI-клавиатуру для ответов.
- Отправка звука в DAW/приложение — работает так же как в тренажере слуха. Есть выбор: сыграть все ноты аккорда одновременно или по очереди, с настраиваемым интервалом и velocity, а также разбить ноты по отдельным MIDI-каналам, если хотите сыграть аккорд например разными инструментами (одна нота на скрипку, вторая на альт, третья на виолончель. Не divisimate 2, но мало ли пригодится).
- Подсказки (значок «i») — подсказка с объяснением.

#### 2. Горячие клавиши

Горячие клавиши работают по физическому расположению клавиши на клавиатуре, поэтому одинаково действуют и на русской, и на английской раскладке.

| Клавиша | Действие |
|---|---|
| **A, B, C, D, E, F, G** | Выбрать ноту на круге. Первое нажатие буквы выбирает её на **мажорном** кольце, повторное нажатие той же буквы — на **минорном** кольце, третье нажатие — снимает выбор. Нажатие другой буквы начинает цикл заново. |
| **Shift + буква** | То же самое, но для диезной ноты (например, Shift+C → C♯). |
| **Пробел, затем буква** | Выбрать бемольную ноту (например, пробел, затем B → B♭). |
| **← / →** | Только во вкладке «Обучение»: поворачивают круг против/по часовой стрелке. |
| **+ / -** | Увеличить/уменьшить масштаб круга. |
| **Shift + -** | Сбросить масштаб круга до 100%. |
| **Q** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение стрелками. |
| **W** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение цветом. |
| **R** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение стрелками. |
| **T** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение цветом. |
| **Y** | Открыть/закрыть панель настроек. |
| **Z** | Во вкладке «Аккорды/Лады»: показать/скрыть подсказку с загаданным аккордом/ладом. |
| **Колесо мыши** | Во вкладке «Обучение», вне панели настроек: переключает выбранную ноту по кругу — вниз по часовой стрелке, вверх — против. |
| **Средняя кнопка мыши** | Открыть/закрыть панель настроек (только на компьютере). |
| **1–9 и 0** (во вкладке «Аккорды/Лады») | Переключение между типами аккордов, идущими по порядку на экране. |

На телефоне: одновременно 2 нажатия открывают/закрывают панель настроек.

#### 3. Что можно поменять через меню (настройки в интерфейсе)

Все перечисленные пункты находятся в выезжающей панели настроек сбоку от круга (открывается кнопкой Н/Y, свайпом, средней кнопкой мыши).

- Отображать настройки: слева / по центру / справа.
- Выбор типа аккорда — Мажор/Минор, Sus2, Sus4, а также 7, maj7, m7, m(Maj7), add9, m(add9), 9, maj9, m9, m(Maj9), add11, m(add11), 11, maj11, m11, 13, maj13, m13, m(Maj13).
- Выбор лада — Лидийский, Мажор, Миксолидийский, Дорийский, Минор, Фригийский, Локрийский, Гармонический минор, Мелодический минор.
- Вариант отображения — стрелками / цветом, отдельно для «Варианта 1» и «Варианта 2» (двух разных стилей показа стрелок).
- Показывать буквы аккорда под нотами.
- Показывать ступени аккорда (выбранная нота становится тоникой).
- Привязать тональность — фиксирует текущую тональность, чтобы круг не «прыгал» при переключении аккордов/ладов.
- Показывать клавиатуру — мини-пианино рядом с кругом.
- Показать альтернативную ноту на мажорном/минорном кругу — включает показ энгармонически равной ноты (например, A♯ вместо B♭) для 5 «спорных» нот по отдельности.
- MIDI-настройки: MIDI вход, MIDI выход, кнопка «Подключить MIDI клавиатуру».
- Настройки отправки аккорда в DAW: «за раз» (все ноты одновременно) или «по очереди» (ноты друг за другом), интервал между нотами (в секундах), Velocity (0–127), формат выхода — midi 1 и midi 2 (второй не проверял, работает вроде с Windows 11 24H2).

#### 4. Что можно поменять через настройки внутри файла

Эти настройки нельзя изменить через интерфейс — их правят прямо в тексте HTML-файла (в редакторе кода или даже в блокноте), в самом начале файла, в блоке `<style>`. Все важные места отмечены комментариями на русском прямо в коде.

- Цвета подсветки на круге — переменные `--green` (правильный ответ), `--red` (ошибка/замена ноты), `--green-flash`, `--red-flash` (та же подсветка, но с прозрачностью).
- Цвет подсветки формулы в подсказках (i) — переменная `--tip-formula-red`.
- Цвета стрелок-подсказок во вкладке «Обучение» — `--blue`, `--cyan`, `--yellow`, `--orange`, `--purple`, `--lime`.
- Цвет колец круга — `--ring-major` (внешнее, мажорное кольцо), `--ring-minor` (среднее, минорное кольцо), `--ring-note` (кольцо с названиями нот), а также цвета при наведении курсора `--ring-major-hover`, `--ring-minor-hover`.
- Цвета клавиш мини-пианино — `--piano-white-key`, `--piano-black-key`, `--piano-key-label-on-white`, `--piano-key-label-on-black`.

Каждая из пяти цветовых тем (Тёмная, Серо-жёлтая, Чёрно-оранжевая, Тёмно-синяя, Светлая) — это свой отдельный набор таких же переменных, поэтому один и тот же цвет можно перенастроить отдельно для каждой темы.

### Ноты

Приложение для заучивания и тренировки чтения нот, ладов (тональностей) и ритма.

Приложение состоит из трёх подразделов (вкладки вверху): **Ноты**, **Лады**, **Ритм**.

#### 1. Функционал приложения

**Раздел «Ноты»**
Работает так: на нотном стане отображается нота — надо выбрать какая это нота на клавиатуре под станом или на пк/миди клавиатуре. Правильный ответ = зелёный, неправильный — красный. Можно включить подсказку предыдущего ответа — понять, что выбрал неверно.
- Сложность — можно выбрать одну, 2 ноты или аккорд.
- Ключ — можно выбрать скрипичный, басовый или оба ключа.
- Разрешённые ноты — можно выбрать нужный набор нот для заучивания. 2 ноты — случайный выбор второй ноты. Для аккордов это выбор тоники.
- Добавочные линейки — можно выбрать от нуля до трёх.
- Обращения аккордов — работает для аккордов. Третье обращение появляется только если оно есть.
- Кнопки ответов — можно скрыть кнопки ответов под нотным станом (если отвечаешь на пк/миди клавиатуре).
- Миди клавиатура — можно подключить миди клавиатуру и отвечать на ней.
- Указывать октаву в ответе (от 2-й до 6-й) — под нотами появляется выбор октавы. Если галочка не поставлена — ответ правильной нотой в любой октаве засчитывается верным.
- Отображать клавиатуру — для удобства выбора нот.
- Рисовать ноты разной длительности — ноты отличаются только на вид.
- Цвета клавиатуры — можно поменять цвета клавиш.
- Выбор языка.
- Выбор темы (все темы на вид могут слегка отличаться в разных вкладках).
- Показывать ноту на стане в подсказке — если включена подсказка о прошлом вопросе, эта галочка добавляет эти ноты на стан рядом с вопросом — красным (если выбрано неверно), зелёным (если верно).
- Прозрачность цвета на клавишах — цвета правильного и неправильного ответа, которыми подсвечиваются клавиши нот.
- Цвета оформления — можно сменить на другие.
- Положение окна ошибок — можно подвинуть выше-ниже и правее-левее.
- Отображать настройки — перемещает окно влево-вправо или в центр экрана.

Показывает одну ноту (или несколько нот/аккорд) на нотном стане, нужно выбрать правильную.

**Раздел «Лады»**
Служит для заучивания ладов/тональностей. Отображается нота — надо достроить остальные ноты лада.
- Ключ — скрипичный, басовый или оба одновременно.
- Выбор ноты, от которой строить лад.
- Выбор, какие лады показывать в вопросах.
- Начинать со случайной ступени — надо построить лад не от первой ступени (внизу написана ступень и лад).
- Надпись названия лада — ползунки для изменения расположения и размера шрифта.
- Расположение и размер шрифта подсказки.
- Положение окна ошибок.
- Отображать настройки — перемещает окно влево-вправо или в центр экрана.
- Подключение миди клавиатуры.

**Раздел «Ритм»**
Состоит из двух режимов:

«Одна нота» — на экране показывается одна нота с определённой длительностью (например, четверть, восьмая), нужно нажать кнопку с правильным названием длительности.
- Можно выбрать, какие длительности отображать (целые, половинные, четверти, восьмые, шестнадцатые, с точкой и т.д.).
- Отвечать можно мышью, цифрами на клавиатуре или через MIDI-клавиатуру.

«Бесконечно» — ноты с ритмом непрерывно «едут» по экрану слева направо, нужно вовремя нажимать (тапать), попадая в ритм каждой ноты.
- Размер такта — можно выбрать 4/4, 3/4, 2/4, 6/8.
- Длительность ноты — можно выбрать несколько длительностей ноты.
- Скорость прокрутки — чем больше значение, тем быстрее едут ноты на экране.
- Метроном во время ритма — можно отключить, если мешает.
- Дробление метронома — можно включить метроном под другой такт (например, для 4/4 можно включить 1/8, и за каждую долю такта будет 2 удара, а не 1).
- Калибровка задержки — для точности звука метронома.

**Общее для всего приложения**
- Пять тем оформления.
- Поддержка трёх языков: русский, английский, китайский (упрощённый).
- Окно ошибок можно двигать по экрану и настраивать, с какой стороны появляется панель настроек.
- Поддержка мобильных устройств: открытие/закрытие меню — 2 нажатия одновременно, окно ошибок — 3 нажатия одновременно. Мобильную версию доделал не полностью — что-то работает, что-то нет. В целом версия рассчитана на ПК.

#### 2. Горячие клавиши (для компьютера)

| Клавиша | Действие |
|---|---|
| **W** (или **Ц**) / **Y** (или **Н**) / **Средняя кнопка мыши** | Открыть/закрыть панель настроек |
| **Q** (или **Й**) | Открыть/закрыть окно статистики ошибок |
| **+** / **-** | Увеличить/уменьшить масштаб нотного стана |
| **Shift + -** | Сбросить масштаб к значению по умолчанию (100%) |
| **A, B, C, D, E, F, G** | Ответить нотой (в разделах «Ноты» и «Лады»), работает и в русской раскладке ЙЦУКЕН |
| **Shift + буква ноты** | Ответить нотой с диезом (например, Shift+C = C#) |
| **Space, затем нота** | Ответить нотой с бемолем (например, Space затем D = Db) |
| **2–6** (после ноты, если включено указание октавы) | Указать номер октавы |
| **R** (или **К**) | Показать подсказку (название ноты), пока клавиша зажата |
| **T** (или **Е**) | Закрепить/открепить подсказку на экране |
| **Z** (или **Я**) | Показать на нотном стане подписи линеек, пока клавиша зажата |
| **1–9, 0** | В «Ритм → Одна нота»: быстрый ответ — цифра соответствует порядковому номеру кнопки длительности слева направо |
| **1–7** | В «Ритм → Одна нота»: быстрый ответ только для миди клавиатуры, от C до B любой октавы |
| **Пробел** | В «Ритм → Бесконечно»: тап (нажатие в ритм); также используется во время калибровки задержки звука |

#### 3. Что можно поменять через меню настроек (без изменения файла)

Панель настроек открывается клавишей **W** и содержит разные блоки в зависимости от выбранного раздела (Ноты / Лады / Ритм).

**Настройки раздела «Ноты»**
- Ключ: скрипичный, басовый или оба сразу.
- Сложность аккордов (простые / средние / сложные).
- Какие именно ноты разрешены (сеткой — можно включать/выключать каждую).
- Добавочные линейки (0, +1, +2, +3).
- Обращения аккордов (можно включить несколько).
- Показывать или скрывать кнопки ответов на клавиатуре под станом.
- Подключение MIDI-клавиатуры (выбор конкретного MIDI входа/выхода).
- Указывать ли октаву в ответе; показывать ли на экране клавиатуру пианино.
- Рисовать ли ноты разными длительностями (меняет только внешний вид).
- Цвета клавиш пианино (белые/чёрные).
- Язык интерфейса, тема оформления, показывать ли ноту на стане в подсказке, положение и размер подсказки.
- Цвет и прозрачность подсветки правильного/неправильного ответа на клавишах.
- Цвета оформления: фон страницы, цвет ключа, цвет линий стана, цвет фона стана.
- Положение окна статистики ошибок.
- С какой стороны экрана появляется панель настроек.

**Настройки раздела «Лады»**
- Ключ, тоники (с каких нот могут начинаться лады, можно несколько).
- Какие лады/тональности включены в тренировку.
- С какой ступени лада начинать.
- Язык, тема оформления.
- Положение и размер надписи с названием текущего лада.
- Цвет, положение и размер подсказки.
- Положение окна статистики ошибок.
- Сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Настройки раздела «Ритм» → «Одна нота»**
- Какие длительности нот разрешены.
- Положение окна статистики ошибок.
- Язык, тема оформления, сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Настройки раздела «Ритм» → «Бесконечно»**
- Размер такта (можно несколько одновременно).
- Какие длительности/элементы ритма могут встречаться.
- Скорость прокрутки нот по экрану (влияет только на картинку, не на сам ритм).
- Темп метронома (BPM) и его громкость; включение звука метронома во время игры; дробление метронома.
- Калибровка звуковой задержки (кнопка «Откалибровать»).
- Язык, тема оформления, сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Окно статистики ошибок (открывается клавишей Q)**
- Для каждого раздела — своя статистика (по нотам отдельно для скрипичного/басового ключа, по ладам/ступеням, по длительностям).
- Кнопка «Очистить историю» для каждой статистики отдельно.
- Размер шрифта окна статистики.

#### 4. Что можно поменять только через правку самого файла (в коде)

Эти параметры не вынесены в меню настроек — чтобы их изменить, нужно открыть HTML-файл в текстовом редакторе и поправить значение вручную.

- Правило «не повторять одну и ту же ноту подряд»: максимальная глубина запрета повтора (сейчас — не более 3 последних нот подряд не повторяются).
- Список поддерживаемых аккордов и то, из каких нот они состоят.

- Список длительностей нот, доступных в разделе «Ритм».

- Чувствительность мобильных жестов: насколько можно сдвинуть пальцы и сколько времени должно пройти, чтобы касание всё ещё считалось «тапом», а не прокруткой.

### Слух

Приложение для тренировки и развития слуха: угадывание нот, интервалов и аккордов на слух. Есть поддержка MIDI-клавиатуры.

#### 1. Функции приложения

**Три режима тренировки**
- Ноты — проигрывается одна нота, нужно выбрать какая.
- Интервалы — проигрываются две ноты (интервал), нужно выбрать, какой это интервал (например, «большая терция»).
- Аккорды — проигрывается аккорд (несколько нот одновременно), нужно выбрать аккорд.

**Как отвечать**
Ответ можно дать несколькими способами одновременно:
- Мышью/нажатие на ноты — нажать на клавиши пианино на экране (или на кнопку с названием интервала/аккорда).
- Клавиатурой компьютера — клавиши A–G обозначают ноты (раскладка клавиатуры не важна, работает и русская, и английская).
- MIDI-клавиатурой — если подключить MIDI-клавиатуру, можно играть ответ прямо на ней.

**Проверка ответа**
- После ответа приложение подсвечивает зелёным правильные ноты и красным — неправильные (в том числе если ноты нажаты не в том порядке).
- Если ответ неверный, показывается пояснение: что было нажато и что нужно было нажать (нота, направление интервала, октава, обращение аккорда — смотря что не так).
- После правильного ответа приложение само переходит к следующему вопросу.

**Настройки**
Для каждого режима можно выбрать:
- какие ноты/интервалы/аккорды использовать в тренировке (можно несколько сразу, приложение будет чередовать их случайно);
- от какой ноты (нот) строить интервал/аккорд;
- в каких октавах играть вопрос;
- для аккордов — какое обращение аккорда использовать и насколько широко могут быть «растянуты» ноты аккорда;
- для интервалов — направление (вверх/вниз) и насколько широко может быть «растянут» интервал (в пределах одной октавы или шире).

**Звук**
- Можно слушать звук прямо в браузере (выбор из набора инструментов: рояль, гитара, скрипка, труба, флейта, хор и другие) или выводить звук через MIDI в DAW (нужен виртуальный кабель вроде Loopbe или аналог).
- Регулировка громкости.

**MIDI**
- Подключение внешней MIDI-клавиатуры для ответа.
- Приложение реагирует на колесо (питч-бенд) MIDI-клавиатуры: покрутить колесо вверх — повторить вопрос, покрутить вниз — новый вопрос.

**Прочее**
- 5 цветовых тем оформления и 2 варианта цвета для правильных/неправильных ответов (обычный и «неоновый» с подсветкой).
- 3 языка интерфейса: русский, English, 简体中文 (определяется автоматически по языку браузера, можно переключить вручную).
- На мобильных устройствах часть функционала не работает. Приложение задумывалось под ПК.

#### 2. Горячие клавиши

| Клавиша | Действие |
|---|---|
| **A, B, C, D, E, F, G** | Ввод ответа нотой (нота нажимается как на пианино). Работает независимо от раскладки клавиатуры. |
| **Shift + буква нот** | Диез (например, Shift+D — D♯). |
| **Пробел, затем буква ноты** | Бемоль (например, пробел, потом G — G♭). |
| **Пробел** (после того, как ответ уже дан) | Перейти к следующему вопросу. |
| **Колесо мыши вверх** | Повторить текущий вопрос. |
| **Колесо мыши вниз** | Перейти к новому вопросу (можно в любой момент, даже до ответа). |
| **Средняя кнопка мыши** или **Y (Н)** | Открыть/закрыть панель настроек. |
| **Тап двумя пальцами** (на телефоне/планшете) | Открыть/закрыть панель настроек. |

#### 3. Что можно поменять через меню (панель настроек в приложении)

**Выбор режима** — вкладки «Ноты» / «Интервалы» / «Аккорды» вверху страницы.

**Что тренировать:**
- нота(ы) / интервал(ы) / аккорд(ы) — что именно должно попадаться в вопросах;
- нота, от которой строить интервал или аккорд;
- обращения аккорда (для аккордов, у которых это применимо);
- направление интервала (вверх/вниз);
- ширина интервала и ширина аккорда;
- октава(ы), в которых звучит вопрос;
- проверка октавы — «точная» или «любая».

**Расположение и вид:**
- расположение панели настроек — слева / по центру / справа;
- тема оформления (5 вариантов);
- цвет ответа — обычный или «неоновый» со свечением.

**Язык интерфейса** — русский / English / 简体中文.

**Звук:**
- вывод звука — через браузер («Онлайн») или через MIDI-выход в DAW (нужен виртуальный кабель Loopbe или аналог);
- при выводе через браузер — выбор инструмента (тембра) и громкости;
- при выводе через MIDI — выбор MIDI-выхода, MIDI-канала и значения velocity.

**MIDI-вход** — подключение MIDI-клавиатуры кнопкой «Подключить MIDI» и выбор конкретного MIDI-устройства, если их несколько.

Чтобы подключить звук из своего приложения или DAW:
1. Указать вход для миди — ваша миди клавиатура.
2. Указать выход для миди — в Loopbe это Internal MIDI.
3. В DAW/вашей программе (например, Pianoteq) выбрать Internal MIDI как входной сигнал. С клавиатуры не передаётся никакой сигнал в DAW/вашу программу. Нажатие срабатывает в программе, а она уже шлёт сигнал миди в DAW/вашу программу с выбранной velocity в настройках. Pitch bend не передаётся, поэтому искажения сигнала не будет. Если слышите что-то лишнее — смотрите входы в DAW/вашей программе. Подключить можно любой инструмент, использующий миди.

#### 4. Что можно поменять только через настройки внутри файла

Эти параметры не выведены в меню — их можно поменять, открыв файл и отредактировав блок в начале `<script>` (отмечен комментарием «НАСТРОЙКИ ТРЕНАЖЁРА»):

```js
window.EAR_TRAINER_CONFIG = {
  velocityMin: 50,             // минимальная громкость (velocity) ноты при воспроизведении вопроса
  velocityMax: 100,            // максимальная громкость (velocity) ноты при воспроизведении вопроса
  noteDurationMs: 900,         // длительность звучания одной ноты, в миллисекундах
  chordStrumMs: 0,             // задержка между нотами аккорда при проигрывании
  defaultMidiChannel: 1,       // MIDI-канал, который выбран по умолчанию для вывода звука через MIDI
  midiAnswerDebounceMs: 350,   // сколько ждать после последней нажатой на MIDI-клавиатуре ноты, прежде чем проверить ответ
};
```

### Ear Trainer

An app for training and developing your ear: recognizing notes, intervals, and chords by ear. MIDI keyboard support included.

#### 1. App features

**Three training modes**
- Notes — a single note is played; you pick which one it is.
- Intervals — two notes (an interval) are played; you pick which interval it is (e.g., "major third").
- Chords — a chord (several notes at once) is played; you pick the chord.

**How to answer**
You can answer in several ways at once:
- Mouse/click — click the on-screen piano keys (or a button with the interval/chord name).
- Computer keyboard — the A–G keys represent notes (keyboard layout doesn't matter, works on both Russian and English layouts).
- MIDI keyboard — if connected, you can play your answer directly on it.

**Answer checking**
- After answering, the app highlights correct notes in green and wrong ones in red (including when notes are pressed in the wrong order).
- If the answer is wrong, an explanation is shown: what was pressed and what should have been pressed (note, interval direction, octave, chord inversion — whichever applies).
- After a correct answer, the app automatically moves to the next question.

**Settings**
For each mode you can choose:
- which notes/intervals/chords to use in practice (several at once, the app will alternate them randomly);
- which note(s) to build the interval/chord from;
- which octaves the question is played in;
- for chords — which inversion to use and how widely the chord notes can be "spread";
- for intervals — direction (up/down) and how widely the interval can be "spread" (within one octave or wider).

**Sound**
- You can listen right in the browser (choice of instruments: piano, guitar, violin, trumpet, flute, choir, and others) or output sound via MIDI to a DAW (requires a virtual cable like LoopBe or similar).
- Volume control.

**MIDI**
- Connect an external MIDI keyboard to answer.
- The app responds to the MIDI keyboard's pitch-bend wheel: rolling it up repeats the question, rolling it down loads a new question.

**Other**
- 5 color themes and 2 color styles for correct/incorrect answers (normal and "neon" glow).
- 3 interface languages: Russian, English, Simplified Chinese (auto-detected from browser language, can be switched manually).
- Some functionality doesn't work on mobile devices. The app was designed for PC.

#### 2. Keyboard shortcuts

| Key | Action |
|---|---|
| **A, B, C, D, E, F, G** | Answer with a note (pressed like on a piano). Works regardless of keyboard layout. |
| **Shift + note letter** | Sharp (e.g., Shift+D — D♯). |
| **Space, then note letter** | Flat (e.g., Space, then G — G♭). |
| **Space** (after already answering) | Go to the next question. |
| **Mouse wheel up** | Repeat the current question. |
| **Mouse wheel down** | Go to a new question (works at any time, even before answering). |
| **Middle mouse button** or **Y** | Open/close the settings panel. |
| **Two-finger tap** (on phone/tablet) | Open/close the settings panel. |

#### 3. What you can change via the menu (in-app settings)

**Mode selection** — the "Notes" / "Intervals" / "Chords" tabs at the top of the page.

**What to practice:**
- note(s) / interval(s) / chord(s) — what should appear in the questions;
- the note to build the interval or chord from;
- chord inversions (for chords where applicable);
- interval direction (up/down);
- interval width and chord width;
- octave(s) the question is played in;
- octave checking — "exact" (must guess the exact octave played) or "any" (octave doesn't matter).

**Layout and appearance:**
- settings panel position — left / center / right;
- theme (5 options);
- answer color — normal or "neon" glow.

**Interface language** — Russian / English / Simplified Chinese.

**Sound:**
- sound output — through the browser ("Online") or via MIDI output to a DAW (requires a virtual cable like LoopBe or similar);
- for browser output — choice of instrument (timbre) and volume;
- for MIDI output — choice of MIDI output, MIDI channel, and velocity value.

**MIDI input** — connect a MIDI keyboard with the "Connect MIDI" button and select a specific MIDI device if there's more than one.

To route sound into your own app or DAW:
1. Set the MIDI input to your MIDI keyboard.
2. Set the MIDI output — in LoopBe this is "Internal MIDI".
3. In your DAW/app (e.g., Pianoteq) select "Internal MIDI" as the input. No signal is sent from the keyboard directly to the DAW/app. The keypress is processed by this app, which then sends a MIDI signal to the DAW/app with the velocity set in the settings. Pitch bend is not passed through, so there's no signal distortion. If you hear anything unexpected, check the inputs in your DAW/app. Any MIDI-capable instrument can be connected this way.

#### 4. What can only be changed via in-file settings

These settings aren't exposed in the menu — you can change them by opening the file and editing the block near the top of `<script>` (marked with the comment "НАСТРОЙКИ ТРЕНАЖЁРА" / "TRAINER SETTINGS"):

```js
window.EAR_TRAINER_CONFIG = {
  velocityMin: 50,             // minimum velocity of the note when playing the question
  velocityMax: 100,            // maximum velocity of the note when playing the question
  noteDurationMs: 900,         // how long a single note plays, in milliseconds
  chordStrumMs: 0,             // delay between chord notes when played (0 = all notes at once; higher = a "strummed" chord)
  defaultMidiChannel: 1,       // default MIDI channel used for MIDI sound output
  midiAnswerDebounceMs: 350,   // how long to wait after the last MIDI note press before checking the answer
};
```

### 音符

一款用于学习和练习读谱、调式（调性）和节奏的应用。

应用包含三个部分（顶部标签页）：**音符**、**调式**、**节奏**。

#### 1. 应用功能

**"音符"部分**
运作方式：五线谱上显示一个音符——需要在谱表下方的键盘或电脑/MIDI 键盘上选出这是哪个音符。答对为绿色，答错为红色。可以开启上一题答案的提示，了解自己选错在哪里。
- 难度——可选单音、双音或和弦。
- 谱号——可选高音谱号、低音谱号或两者同时。
- 允许的音符——可选择要练习的音符范围。双音模式下，第二个音符随机选取；和弦模式下，这是选择根音。
- 加线——可选择 0 到 3 根。
- 和弦转位——适用于和弦，第三转位只在存在时才会出现。
- 答题按钮——可隐藏谱表下方的答题按钮（如果用电脑/MIDI 键盘作答）。
- MIDI 键盘——可连接 MIDI 键盘作答。
- 在答案中注明八度（2 至 6 度）——勾选后音符下方会出现八度选择；不勾选时，任意八度中答对音符即算正确。
- 显示键盘——方便选择音符。
- 绘制不同时值的音符——仅影响外观。
- 键盘颜色——可更改琴键颜色。
- 语言选择。
- 主题选择（各标签页下同一主题外观可能略有不同）。
- 在提示中显示谱表上的音符——若开启了上一题提示，此选项会在题目旁的谱表上也显示这些音符：选错为红色，选对为绿色。
- 琴键高亮透明度——正确/错误答案高亮琴键所用的颜色透明度。
- 主题配色——可更改。
- 错误窗口位置——可上下左右移动。
- 显示设置——将面板移到左/右或居中。

在五线谱上显示一个音符（或多个音符/和弦），需要选出正确答案。

**"调式"部分**
用于学习调式/调性。显示一个音符——需要补全该调式的其余音符。
- 谱号——高音谱号、低音谱号或两者同时。
- 选择作为调式起始的音符。
- 选择题目中出现哪些调式。
- 从随机级数开始——不从第一级开始构建调式（下方会标注级数和调式名称）。
- 调式名称标签——可用滑块调整位置和字号。
- 提示的位置和字号。
- 错误窗口位置。
- 显示设置——将面板移到左/右或居中。
- 连接 MIDI 键盘。

**"节奏"部分**
包含两种模式：

"单音符"——屏幕上显示一个具有特定时值的音符（例如四分音符、八分音符），需要按下对应时值名称的按钮。
- 可选择显示哪些时值（全音符、二分音符、四分音符、八分音符、十六分音符、附点音符等）。
- 可用鼠标、数字键或 MIDI 键盘作答。

"无限模式"——带节奏的音符从屏幕右侧持续向左滚动，需要在每个音符的节拍点及时点击（敲击）。
- 拍号——可选 4/4、3/4、2/4、6/8。
- 音符时值——可选择多种时值。
- 滚动速度——数值越大，音符移动越快。
- 节奏进行中的节拍器——如果干扰可以关闭。
- 节拍器细分——可以让节拍器以不同的细分演奏（例如 4/4 拍下开启 1/8 细分，每一拍会有 2 次敲击而不是 1 次）。
- 延迟校准——用于校正节拍器声音的准确性。

**整个应用的通用功能**
- 五种配色主题。
- 支持三种语言：俄语、英语、简体中文。
- 错误窗口可在屏幕上移动，并可设置设置面板出现的方向。
- 移动设备支持：打开/关闭菜单需同时点击两下，错误窗口需同时点击三下。移动端版本尚未完全适配——部分功能可用，部分不可用。整体上该版本主要面向电脑设计。

- 输入音符字母后等待八度数字的时间（目前为 3 秒——若未及时输入八度，答案会被重置）。
- 错误统计窗口水平和垂直方向的移动范围限制。
- 移动端手势灵敏度：手指可移动的距离范围及需经过多长时间，触摸才仍被视为"点击"而非滑动。
- 五线谱内部尺寸（线间距、谱号位置等）。

### 耳朵训练

一款用于训练和提升听力的应用：通过听力辨别音符、音程和和弦。支持 MIDI 键盘。

#### 1. 应用功能

**三种训练模式**
- 音符——播放一个音符，需要选出是哪一个。
- 音程——播放两个音符（一个音程），需要选出是哪种音程（例如"大三度"）。
- 和弦——播放一个和弦（多个音符同时响起），需要选出是哪个和弦。

**作答方式**
可以同时用多种方式作答：
- 鼠标点击音符——点击屏幕上的钢琴键（或点击带有音程/和弦名称的按钮）。
- 电脑键盘——A–G 键代表音符（键盘布局无关紧要，俄语和英语布局都可用）。
- MIDI 键盘——若已连接 MIDI 键盘，可直接在其上演奏答案。

**答案检查**
- 作答后，应用会将正确音符高亮为绿色，错误音符高亮为红色（包括音符按下顺序不对的情况）。
- 若答案错误，会显示说明：实际按下了什么、应该按下什么（音符、音程方向、八度、和弦转位——具体取决于错在哪里）。
- 答对后，应用会自动进入下一题。

**设置**
每种模式都可以设置：
- 训练中使用哪些音符/音程/和弦（可同时选多个，应用会随机切换）；
- 从哪个（些）音符构建音程/和弦；
- 题目在哪些八度中播放；
- 对于和弦——使用哪种转位，以及和弦音符可以"展开"多宽；
- 对于音程——方向（上行/下行），以及音程可以"展开"多宽（限于一个八度内还是更宽）。

**声音**
- 可以直接在浏览器中听声音（可选乐器：钢琴、吉他、小提琴、小号、长笛、合唱等），也可以通过 MIDI 输出到 DAW（需要 LoopBe 之类的虚拟声卡）。
- 音量调节。

**MIDI**
- 连接外部 MIDI 键盘作答。
- 应用会响应 MIDI 键盘的滚轮（弯音轮）：向上转动重复当前题目，向下转动切换到新题目。

**其他**
- 5 种配色主题，以及正确/错误答案的 2 种颜色风格（普通和带光效的"霓虹"）。
- 3 种界面语言：俄语、English、简体中文（根据浏览器语言自动检测，也可手动切换）。
- 移动设备上部分功能无法使用。该应用主要面向电脑设计。

#### 2. 快捷键

| 按键 | 操作 |
|---|---|
| **A, B, C, D, E, F, G** | 用音符作答（按下方式如同弹钢琴）。与键盘布局无关。 |
| **Shift + 音符字母** | 升号（例如 Shift+D — D♯）。 |
| **空格，然后音符字母** | 降号（例如空格后按 G — G♭）。 |
| **空格**（已作答后） | 进入下一题。 |
| **鼠标滚轮向上** | 重复当前题目。 |
| **鼠标滚轮向下** | 切换到新题目（任意时刻均可，包括作答前）。 |
| **鼠标中键** 或 **Y** | 打开/关闭设置面板。 |
| **双指点击**（手机/平板） | 打开/关闭设置面板。 |

#### 3. 通过菜单可更改的内容（应用内设置）

**模式选择**——页面顶部的"音符"/"音程"/"和弦"标签页。

**训练内容：**
- 音符/音程/和弦——题目中具体出现哪些内容；
- 构建音程或和弦的起始音符；
- 和弦转位（适用于相关和弦）；
- 音程方向（上行/下行）；
- 音程宽度和和弦宽度；
- 题目播放的八度；
- 八度检查方式——"精确"（需猜中实际播放的八度）或"任意"（八度不作要求）。

**布局和外观：**
- 设置面板位置——左 / 居中 / 右；
- 主题（5 种）；
- 答案颜色——普通或带光效的"霓虹"。

**界面语言**——俄语 / English / 简体中文。

**声音：**
- 声音输出方式——通过浏览器（"在线"）或通过 MIDI 输出到 DAW（需要 LoopBe 之类的虚拟声卡）；
- 浏览器输出时——选择乐器（音色）和音量；
- MIDI 输出时——选择 MIDI 输出、MIDI 通道和 velocity 值。

**MIDI 输入**——通过"连接 MIDI"按钮连接 MIDI 键盘，若有多个设备可选择具体的 MIDI 设备。

要将声音接入自己的应用或 DAW：
1. 将 MIDI 输入设为你的 MIDI 键盘。
2. 将 MIDI 输出设为对应设备——在 LoopBe 中为 Internal MIDI。
3. 在你的 DAW/程序（例如 Pianoteq）中，将 Internal MIDI 设为输入信号。键盘本身不会向 DAW/程序传送任何信号；按键会在本应用中触发，再由本应用按设置中的 velocity 值向 DAW/程序发送 MIDI 信号。弯音（Pitch bend）不会被传送，因此不会造成信号失真。如果听到多余的声音，请检查 DAW/程序中的输入设置。可连接任何支持 MIDI 的乐器。

#### 4. 只能通过文件内部设置更改的内容

这些参数未在菜单中开放——可以打开文件，编辑 `<script>` 开头处标有注释"НАСТРОЙКИ ТРЕНАЖЁРА"（训练器设置）的代码块来修改：

```js
window.EAR_TRAINER_CONFIG = {
  velocityMin: 50,             // 播放题目时音符的最小力度（velocity）
  velocityMax: 100,            // 播放题目时音符的最大力度（velocity）
  noteDurationMs: 900,         // 单个音符的播放时长（毫秒）
  chordStrumMs: 0,             // 播放和弦时音符之间的延迟（0 表示所有音符同时响起；数值越大越像"扫弦"式的分开演奏）
  defaultMidiChannel: 1,       // MIDI 声音输出默认使用的 MIDI 通道
  midiAnswerDebounceMs: 350,   // 在 MIDI 键盘上最后一个音符按下之后，等待多久再检查答案
};
```
